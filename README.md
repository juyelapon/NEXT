# Catalyst Analytics (Next Level) - React.js + Tailwind CSS Landing Page

This project is a high-performance, pixel-perfect, fully interactive React + Tailwind CSS web application converted directly from the official Figma design:
**"Software Development Company Landing Page (Catalyst Analytics)"**

---

## 🚀 Features Included & Implemented

1. **Pixel-Perfect Figma Visuals & Dark Mode Theme**:
   - Exact color palettes (`#030303`, `#141414`, `#0A84FF`, `#8961FF`, `#262626`).
   - All high-resolution 3D visual assets, client logos, avatars, and custom SVGs extracted from Figma.
   - Smooth glowing ambient backdrops, glassmorphism, and responsive typography (Barlow, Inter, Lexend).

2. **Interactive Navbar**:
   - Smooth scrolling navigation to `#home`, `#services`, `#why-us`, `#story`, and `#faq`.
   - Dynamic backdrop blur on page scroll.
   - Fully responsive mobile hamburger navigation menu.
   - Quick action CTA for "Contact Us".

3. **Hero Section**:
   - High-impact headline with Figma-accurate blue badge styling.
   - Overlapping verified client avatars social proof.
   - 3D futuristic AI robot graphic with floating real-time metrics cards.
   - Interactive "Book a Meeting" button opening a full booking workflow.

4. **Companies / Partner Logos**:
   - Seamless infinite auto-scrolling marquee ticker.
   - Interactive hover states (pauses marquee on hover).
   - Linear gradient top & bottom borders matching Figma specifications.

5. **Services Section**:
   - "Predictive Analytics", "AI Consulting", and "Data Engineering" cards with 3D graphics.
   - Interactive **"View Details" Modal** displaying detailed feature breakdowns, enterprise deliverables, and supported technology stacks (PyTorch, Kafka, Snowflake, LangChain, etc.).
   - "Request Solution" direct booking trigger.

6. **Why Choose Us Section**:
   - 4 interconnected circular principle badges: Innovation, Collaboration, Excellence, Integrity.
   - Interactive selection state showing verified enterprise metrics.

7. **Why We Started (Story Carousel)**:
   - Interactive quotes carousel with previous/next navigation buttons.
   - Dot indicators and auto-play with pause-on-hover.
   - "Learn More About Our Journey" interactive modal detailing company history.

8. **Interactive FAQ Accordion**:
   - Smooth expand/collapse accordion with number badges.
   - Live real-time search filter to quickly find specific answers.
   - "Ask an Engineer" quick direct contact trigger.

9. **Footer & Quick Links**:
   - Contact links with direct `mailto:`, `tel:`, and Austin TX office badge.
   - Social links (Twitter/X, LinkedIn, GitHub).
   - Functional newsletter subscription with input validation and instant feedback.
   - Interactive Privacy Policy and Terms of Service legal modals.

10. **Interactive Modals & Toasts**:
    - **Meeting Booking Modal**: Multi-step meeting scheduler with date & time pickers, topic selection, form validation, and confirmation reference codes.
    - **Contact Modal**: Inquiry form with topic routing, real-time feedback, and validation.
    - **Custom Toast Notification System**: Non-blocking toast notifications for user interactions.

## 🛠️ How to Run the Project (কিভাবে রান করবেন)

### 1. Requirements
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### 2. Run the Development Server
Open your terminal (PowerShell or Command Prompt) in this folder and run:

```bash
npm run dev
```

Then open your browser and navigate to:
```
http://localhost:3000
```
(or the port shown in your terminal, e.g., `http://localhost:5173`)

### 3. Build for Production
To create an optimized production build:

```bash
npm run build
```

The output will be generated inside the `dist/` directory.

To preview the production build locally:
```bash
npm run preview
```
